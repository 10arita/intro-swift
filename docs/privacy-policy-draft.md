## 1. 対象

本ポリシーは、Kaito Aritaが提供するiPhoneアプリ「IntoL」と、その対戦・フレンド・問い合わせサービスにおける情報の取り扱いを説明します。

## 2. 取り扱う情報と目的

| 情報 | 利用目的・保存先 |
| --- | --- |
| プロフィール識別子・認証情報 | 対戦とフレンド機能の本人確認。認証情報を端末のKeychainと、同期利用時のCloudKit Private Databaseに保存し、サーバーでも認証のために保持します |
| 名前・アイコン | プロフィール表示。端末、同期利用時のCloudKit、対戦サーバーへ保存します |
| 復習、プレイ履歴、成績、称号、ランク、音量設定 | 復習・記録の表示と端末間同期。端末と、同期利用時のCloudKitに保存します。成績の概要は他の利用者への表示のためサーバーにも保存します |
| 旧版でサーバーへ保存された復習、履歴、統計 | 端末・CloudKitへの移行元としてサーバーに残っている場合があります。CloudKitへの取り込みだけでサーバーの旧記録を自動消去するものではありません |
| フレンド関係、申請、招待 | フレンドと対戦へ参加するため、サーバーで保存・処理します。端末の連絡先一覧を読み込む機能ではありません |
| 対戦操作・ルーム情報・選んだ曲の情報 | 出題、準備、再生タイミング、回答の判定、得点計算、通信復帰のためサーバーで処理します |
| アプリ内のご意見の本文、種別、アプリのバージョン、受付識別子 | 不具合調査と改善のため、サーバーを経由して運営者のDiscordへ送信します。プロフィール識別子を含めない匿名の送信です。重複送信を防ぐため、本文等を含む受付記録をサーバーにも保存します |
| サビ位置の報告に含まれる曲情報・再生開始位置・再生方式・アプリのバージョン・受付識別子 | 音楽紹介・復習機能の品質改善のため、サーバーを経由して運営者のDiscordへ送信します。重複送信を防ぐ受付記録をサーバーにも保存します |
| Googleフォームの問い合わせ種別・本文・送信日時、任意の端末情報、返信希望時のメールアドレス | 問い合わせへの対応、不具合調査、データの取り扱いに関する相談のため、Googleフォームと運営者の返信用メールで取り扱います。アプリのプロフィールとは自動的に結び付けません。広告配信・販売促進には利用しません |

対戦サーバーは日本国内に設置されたサーバーを利用します。運営者は、その提供環境のアクセスログやバックアップを自ら管理する運用を行わず、バックアップの定期削除も行っていません。ただし、ログが記録されない、バックアップが作成されない、または90日以内に削除されることを意味するものではありません。

{{ACCESS_LOG_DETAILS}}：外部環境の管理者へ、ログの記録項目・用途・保存先・保存期間を確認して補足する。ユーザー関連データのバックアップと、そのバックアップを削除しない運用はユーザー回答済み。今後の消去方法・保持期限・復元時の対応は未決定であり、現状で消去できると案内しない。

## 3. Apple Musicと外部サービス

Apple Musicへのアクセスは、利用者の許可を得て行います。選んだプレイリストの曲やApple Musicカタログの情報を取得し、本人の再生条件に基づいてMusicKitで再生します。Apple Musicの音声ファイルを運営者のサーバーへ保存・配信することはありません。アクセスの許可はiPhoneの設定から変更できます。

選択肢の作成ではアーティスト名をAppleのiTunes検索APIへ送信します。サビ位置の照合では曲名・アーティスト名などをIntoLのサーバーへ送信します。選曲情報やプレイリストを広告ターゲティングに利用しません。

iCloud同期にはAppleのCloudKit Private Databaseを利用します。同じApple Accountを使用する端末間で復元・同期します。iCloud未接続時には利用できる範囲のデータを端末へ保存します。

アプリ内の匿名のご意見・サビ位置の報告はDiscordで取り扱います。この匿名送信に氏名、住所、メールアドレス等を書き込まないでください。個別の返信はできません。

サポートページにはGoogle Sitesを、返信を希望する問い合わせの受付にはGoogleフォームを利用します。Googleフォームはアプリ内の匿名送信とは別の窓口です。返信を希望する場合に限り、フォームの返信先欄にメールアドレスを入力していただき、運営者のメールから回答します。フォームの回答は一般公開しません。Apple Accountのパスワード、認証コード、支払情報、アプリの認証トークンは送信しないでください。

これらのGoogleサービスでのデータの取り扱いについては、[Googleのプライバシーポリシー](https://policies.google.com/privacy?hl=ja)もご確認ください。運営者側のアクセス情報の閲覧範囲、サイトの解析設定、Googleサービスと返信用メールの契約・保存先等は、下記の委託先・国外取扱いの記載に反映します。

対戦サーバーの国内設置という説明は、Apple、Google、Discord等の外部サービスの情報もすべて国内で取り扱われることを意味しません。

外部サービスの委託先、取扱国、国外での取り扱いの根拠・必要な案内：{{PROCESSORS_AND_INTERNATIONAL_TRANSFERS}}

## 4. 他の利用者へ表示される情報

対戦相手とフレンドに名前、アイコン、成績の概要、称号、最高ランク等を表示します。対戦中は得点、正誤、操作の受付順等を参加者に表示します。公開したくない個人情報を名前や写真へ含めないでください。

## 5. 広告・課金

現在の版には広告SDKを導入しておらず、広告配信とアプリ内課金は行いません。広告や課金を導入する場合は、情報の送信先・項目・目的、追跡の有無や選択方法等を確認し、本ポリシーを更新します。

アプリ内課金を導入する場合、決済はAppleの仕組みを利用し、アプリは購入商品と有効な購入権利を確認します。クレジットカード番号等をIntoLが独自に収集する仕組みは設けていません。

## 6. 保存期間と削除

アカウント画面から、プロフィールと関連データの削除を開始できます。名前・アイコン・復習・履歴・成績・設定、サーバー上のプロフィール・フレンド関係・申請・招待等を対象にします。既知の認証情報で確認できる過去のプロフィールも削除対象とします。認証情報が失われたデータについては、問い合わせフォームで対応方法をご案内します。

iCloud同期を利用している場合は、個人の記録を含まない削除マーカーへ置き換えます。古い記録の復活を防ぐため、削除時点と新しいランダムな識別子等を含むマーカーを残します。サーバーでは削除済みIDと認証トークンのハッシュを、再登録防止と削除再試行の確認に使用します。これらの保持期間・見直し方法：{{DELETION_MARKER_RETENTION}}

運営者がDiscord上で保管するアプリ内の匿名のご意見・サビ位置の報告は、受信日から90日間保存し、その後、運営者が手動で削除します。自動削除は行いません。Googleフォームの問い合わせとは保存期間の起算点が異なります。

サーバーの受付記録と、外部環境で管理されるアクセスログ・バックアップの削除・保持・復元時の取り扱い：{{RETENTION_AND_BACKUP_POLICY}}。Discord上の90日間の方針を、これらの保存先や外部サービス内部の保管まで保証するものとして案内しない。

現在の運用では、プロフィール等のユーザー関連データを含むサーバーのバックアップを作成し、そのバックアップの削除は行っていません。稼働中のデータをアカウント削除機能で削除しても、バックアップ内の複製は消去されず残ります。アプリには外部環境のバックアップを消去する機能はありません。

Googleフォームの問い合わせ本文・返信先・返信メールは、対応完了後90日間保存し、期間経過後に運営者が削除します。アプリのアカウント削除とは別に管理します。問い合わせ内容自体の削除を希望する場合は、問い合わせフォームからご相談ください。対象を特定するため、送信日時・内容の概要や、必要に応じて本人確認に必要な情報をお伺いします。

匿名報告はプロフィールに結び付けていないため、アカウント削除だけでは削除できません。個人情報を誤って送信した場合は問い合わせフォームへご連絡ください。オフライン端末のデータを即座に遠隔削除する機能ではありません。Apple AccountやApple Musicの契約は、この操作では削除・解約されません。

## 7. 安全管理と問い合わせ

認証、通信の保護、アクセス権限の管理等により情報を保護します。開示・訂正・削除等のご相談は上記の問い合わせフォームへご連絡ください。必要に応じて、対象情報と本人確認に必要な事項をご案内します。

本アプリは子ども向け専用のサービスではありません。未成年の方は、情報の取り扱いやApple Musicの契約・通信料等について保護者と相談した上でご利用ください。ご本人が十分に理解して判断することが難しい場合は、保護者と一緒にご確認ください。問い合わせに、対応に不要な氏名・住所・学校名等を記入しないでください。
