# 歌ネットを基準にしたランク曲集の選定

2026年10月13日に指定ページ `https://www.uta-net.com/ranking/total/?sort=pop-d` をブラウザで開き、「もっと見る」で1000位まで表示して曲のメタデータを取得した。歌詞本文は取得していない。元順位1〜1000位の連続性、曲ページ1000件の一意性、全曲の発売日の形式を確認した。

`server/rank-catalog-candidates.json` は出典1000曲と選定判断を保持するデータ。チェック192曲を反映し、2010年以降545曲と合わせた737曲から童謡「きらきら星／カノン」を除いて736曲を選定した。このうち通常録音を照合できた716曲を `server/rank-catalog.json` に反映した。旧200曲の選定と生成グループは廃止し、指定ランキングから選び直している。

追加指定192曲のうち出題曲集に採用できたのは180曲。残る12曲と、日付条件を満たした未照合8曲を合わせた20曲は保留している。追加指定は削除せず、`docs/rank-catalog-pending.md` と `server/rank-catalog-selection.json` に残す。メタデータの照合は実機のサブスクリプション再生可否の確認とは別で、再生できない場合は既存の無効問題の処理で別曲へ置き換える。

## 発売日の条件

- 歌ネットの表に掲載されている発売日が2010年1月1日以降の曲を採用候補とする。
- 対象1000曲のうち採用候補545曲、除外455曲。発売日不明は0曲。
- 掲載日は初出日とは限らない。例えばHY「366日」は表に2018年8月22日と掲載されているため、この条件では採用候補となる。曲の初出日を調べ直した一覧ではない。
- 対象は元の1000位までに限定する。除外分を1001位以降から補充しない。

## ランク候補

除外後も元順位を維持し、100位ごとに区切る。

| 元順位 | ランク | 出題曲数 |
| --- | --- | ---: |
| 1〜100 | E | 97 |
| 101〜200 | D | 88 |
| 201〜300 | C | 78 |
| 301〜400 | C+ | 69 |
| 401〜500 | B | 70 |
| 501〜600 | B+ | 67 |
| 601〜700 | A | 64 |
| 701〜800 | A+ | 60 |
| 801〜900 | S | 63 |
| 901〜1000 | S+ | 60 |

順位は累計歌詞アクセス数による人気順であり、イントロの識別難度を測った値ではない。候補データの `difficultyPrior` は既存のランク尺度に対応する仮値。PUSH期限には既存の初期値を使い、曲集は引き続き `provisional` とする。実音源の試遊による校正は未実施。

## 除外曲の確認と次の反映

`outputs/utanet-rank-review-2026-10-13/除外曲一覧.xlsx` の「除外曲」シートに、元順位・曲名・アーティスト・掲載発売日・除外理由・追加希望・追加時の段位候補・曲ページを記載した。「追加希望」列はExcelのセル内チェックボックスで、クリックして追加する曲を指定できる。セルの値はチェックありでTRUE、なしでFALSE。初期状態は全曲チェックなしで、チェック数を自動集計する。「ランキング1000曲」シートには元データと日付による選定を残した。

追加曲は元順位と曲ページIDで特定し、保存された192件のチェックを反映した。童謡・唱歌の名義と童謡「きらきら星」は採用条件から外す。アニメ曲や一般のJ-Popは童謡として一括除外しない。録音情報は `server/rank-recordings.json` に固定する。曲集バージョンは `jp-intro-utanet-2026-10-reviewed-v1` に更新し、旧履歴を新しい曲集の最高記録と比較しない。

候補の初期生成には同形式のメタデータJSONを渡す。初期生成は確認済みの選定判断を上書きするため、通常の再生成は保存済みのレビューと録音情報を使う。

```sh
python3 scripts/prepare_rank_candidates.py /path/to/utanet-top1000.json
python3 scripts/apply_rank_review.py
python3 scripts/collect_rank_metadata.py
python3 scripts/build_rank_catalog.py
```
